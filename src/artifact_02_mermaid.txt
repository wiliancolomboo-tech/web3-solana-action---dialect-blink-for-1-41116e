flowchart TD
    %% Actors and Interfaces
    User([User on X / Dialect Client])
    BlinkUI[Dialect Action / Blink Frontend]
    ActionAPI[Enterprise Solana Action Server]
    DEX[Jupiter Aggregator API v6]
    SolanaRPC[Solana RPC Network]
    VaultProgram[Anchor Yield Vault Program]
    Notifier[Enterprise Discord / Slack Webhook]

    %% Step 1: Metadata Resolution
    User -->|1. Renders URL in Feed| BlinkUI
    BlinkUI -->|2. GET /api/actions/vault-deposit| ActionAPI
    ActionAPI -->|3. Return ActionGetResponse metadata & input params| BlinkUI

    %% Step 2: Transaction Request
    User -->|4. Inputs Amount & Clicks Deposit| BlinkUI
    BlinkUI -->|5. POST /api/actions/vault-deposit payload| ActionAPI
    
    %% Step 3: Transaction Composition
    ActionAPI -->|6. Fetch Best Swap Route if input != target token| DEX
    DEX -->|7. Return Swap Ix / serialized tx| ActionAPI
    ActionAPI -->|8. Fetch Vault State PDA & Share Mint| SolanaRPC
    SolanaRPC -->|9. Return Account Data| ActionAPI
    ActionAPI -->|10. Build & Serialize Combined Atomic VersionedTx| BlinkUI

    %% Step 4: Signing & Execution
    BlinkUI -->|11. Prompt Wallet Sign & Simulate| User
    User -->|12. Submit Signed VersionedTx| SolanaRPC
    SolanaRPC -->|13. Execute Atomic Instruction Set| VaultProgram
    
    %% Step 5: Verification & Notification
    SolanaRPC -->|14. Tx Confirmation ConfirmationStatus: finalized| ActionAPI
    ActionAPI -->|15. Dispatch Audit Event Log| Notifier
    VaultProgram -->|16. Mint Vault Shares to User Wallet| User
